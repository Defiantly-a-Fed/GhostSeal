# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in Ghost Seal, please disclose it responsibly.  Avoid opening public issues with sensitive information.  Instead, email the maintainer at the address provided in the repository profile or open a private issue.  Provide as much detail as possible to reproduce and address the vulnerability.

## Responsible Use

Ghost Seal is designed for authorised security research and defensive use.  Operators must have explicit permission to test or monitor the networks and devices on which Ghost Seal is deployed.  The authors do not condone or support malicious use of this software.
